# Sistema de Eventos

## Descrição
Este projeto é uma interface web simples para visualização de eventos de tecnologia. 
Ele foi desenvolvido como parte de uma atividade prática, com o objetivo de aplicar conceitos de HTML e CSS, 
principalmente o uso de Flexbox para organização de layout.

## Sobre o Projeto
A aplicação simula um sistema onde o usuário pode navegar por eventos, visualizar informações básicas e utilizar filtros para organizar o conteúdo.
O foco principal não está na funcionalidade dinâmica, mas sim na construção visual e estrutural da interface.

## Funcionalidades 
* Exibição de eventos em formato de cards
* Área de filtros para categorização
* Menu de navegação no topo
* Layout organizado e responsivo com Flexbox

 ## Tecnologias Utilizadas
 * HTML
 * CSS
 * VSCODE

## Considerações Finais
Este projeto representa a evolução de uma versão inicial desenvolvida apenas em HTML, sendo posteriormente aprimorado com CSS para oferecer uma melhor experiência visual e organização dos elementos na interface.

Além de atender aos requisitos propostos, o projeto reforça fundamentos essenciais para o desenvolvimento de interfaces web, servindo como base para aplicações mais complexas no futuro
